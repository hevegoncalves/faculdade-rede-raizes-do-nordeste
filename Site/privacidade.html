Política de Privacidade

A privacidade dos nossos clientes é importante. Por isso, apresentamos informações sobre a utilização de dados pessoais durante a navegação e o uso das funcionalidades do site Raízes do Nordeste.

1. Informações que podem ser coletadas

Durante a utilização do site, podem ser solicitadas informações como nome, e-mail, telefone e endereço, principalmente para simular o cadastro do cliente, o preenchimento dos dados de entrega e a realização de pedidos.

2. Como as informações são utilizadas

Neste projeto acadêmico, as informações são utilizadas para demonstrar funcionalidades como cadastro, identificação do cliente, preenchimento dos dados de entrega e acompanhamento simulado dos pedidos.

3. Armazenamento das informações

O protótipo utiliza o armazenamento local do navegador, conhecido como localStorage, para manter determinadas informações entre as visitas ao site. Esses dados ficam associados ao navegador utilizado e não são automaticamente sincronizados com outros dispositivos.

4. Compartilhamento de dados

Este protótipo não implementa, por si só, um serviço real de entrega nem um sistema de processamento de pagamentos. Em uma aplicação comercial, qualquer compartilhamento de dados pessoais deverá ser avaliado conforme a finalidade, a necessidade e a legislação aplicável.

5. Segurança das informações

Este projeto tem finalidade acadêmica e utiliza recursos do navegador para simular algumas funcionalidades. O armazenamento local não deve ser considerado um ambiente seguro para guardar senhas, números completos de cartões ou outros dados financeiros sensíveis.

6. Direitos relacionados aos dados pessoais

A Lei Geral de Proteção de Dados Pessoais (LGPD) prevê direitos aos titulares de dados pessoais, incluindo, nas condições legais aplicáveis, a confirmação da existência de tratamento, o acesso aos dados, a correção de informações incompletas ou desatualizadas e a eliminação de dados desnecessários ou tratados em desconformidade com a legislação.

7. Dúvidas sobre privacidade

Em uma versão real do serviço, deverá existir um canal de contato para receber dúvidas e solicitações relacionadas ao tratamento de dados pessoais.

Sobre este protótipo

O Raízes do Nordeste é um projeto acadêmico desenvolvido para demonstrar a experiência de utilização de um site de restaurante. As informações desta página devem ser revistas caso o projeto passe a operar como um serviço real, considerando as funcionalidades implementadas e as práticas efetivamente adotadas para o tratamento de dados.
